# Счётчик событий

Локальное Android-приложение: следит, сколько времени прошло после события, и подсвечивает его, когда срок приближается или уже вышел.

Примеры: начало использования зубной щётки, смена фильтра воды, замена масла в автомобиле.

Данные хранятся только на устройстве. Аккаунтов и сети нет.

Установка на телефон: скачайте [event-counter-0.2.0.apk](dist/event-counter-0.2.0.apk), откройте файл и подтвердите установку. Если система спросит разрешение, разрешите установку из этого источника. История версий: [VERSIONS.md](VERSIONS.md).

## Что видно сразу

На главном экране у каждого события есть иконка, название и счётчик. Группы открываются внутрь. Событие может лежать в корне или в группе.

Кнопка «Добавить» создаёт событие или группу. Переключатель в шапке меняет вид: список или плитка. Тот же выбор есть в настройках. Иконка архива открывает прошлые события.

## Событие

- Название, краткое и полное описание, тег.
- Иконка из набора по умолчанию. Готовые теги (здоровье, гигиена, авто, вода, дом) подставляют подходящую иконку.
- Несколько фотографий из галереи. Файлы копируются в хранилище приложения.
- Дата и время старта.
- Группа, в том числе корень. Так событие переносится между группами.
- Бессрочный режим: пороги не применяются, цвет статуса не меняется.
- Архив. Кнопка на карточке сразу убирает событие с главного экрана. Дата, когда оно произошло, остаётся в архиве. Оттуда событие можно открыть или вернуть. Так несколько замен масла не загромождают текущий счётчик: на экране остаётся последняя, остальные лежат рядом по названию и дате.

Пороги задаются числом и единицей: часы, дни, недели, месяцы.

- Жёлтый — пора готовиться.
- Красный — срок вышел.
- Красный порог должен наступать позже жёлтого.

Месяц считается календарно, неделя — 7 дней.

## Счётчик

Направление:

- **Прошло** — секундомер от момента события.
- **До красного** — таймер до красного порога. Доступен, только если красный порог задан и событие не бессрочное. После срока счётчик показывает просрочку.

Единицы: дни (по умолчанию), часы, минуты, секунды, часы и минуты. Иконка рядом со счётчиком соответствует направлению.

## Группы

У группы есть название и иконка. Группы вкладываются друг в друга. Удаление группы не удаляет содержимое: вложенные группы и события поднимаются на уровень выше.

## Настройки

- Вид: список или плитка.
- Ключ API и базовый URL для будущей генерации изображений. Значения сохраняются локально и пока никуда не отправляются.

## Сборка

Нужны JDK 17+, Android SDK с платформой API 37 и Android Studio, которая собирает проекты на Android Gradle Plugin 9.3.

| | |
|---|---|
| minSdk | 26 |
| targetSdk | 35 |
| compileSdk | 37 |
| Версия | 0.2.0 |
| Пакет | `com.eventcounter` |

```text
gradlew.bat :app:assembleDebug
gradlew.bat :app:testDebugUnitTest
```

Отладочный APK: `app/build/outputs/apk/debug/app-debug.apk`.

`local.properties` с путём к SDK в репозиторий не входит. Android Studio создаёт его сама.

## Структура

```text
app/src/main/java/com/eventcounter/
  domain/          модели, статус, счётчик, дерево групп
  data/local/      Room: группы, события, изображения
  data/prefs/      DataStore: вид и ключи ИИ
  di/              AppContainer
  ui/home/         корень и вложенные группы
  ui/event/        создание и правка события
  ui/group/        создание и правка группы
  ui/settings/     настройки
```

Расчёт статуса и счётчика не хранится в базе: он считается от текущего времени в `StatusCalculator`.
